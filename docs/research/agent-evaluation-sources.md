# 轨迹风险审计测量体系的一手资料

已阅读用户粘贴的鸭哥文章正文。文章用语义检索举例，先人工厘清相关性标准，用现有系统建立基线，再测不同方案的效果和代价。对应到轨迹审计，先用边界样本校准标注规则，再通过基线错例确定优化方向。[超线性学院原文](https://www.superlinear.academy/c/recording/ai-01)

## 来源与项目用法

| 来源 | 已核对的做法或发现 | 对本项目的建议 |
| --- | --- | --- |
| [Anthropic 智能体评测实践](https://www.anthropic.com/research/demystifying-evals-for-ai-agents) | 从 20–50 个实际失败案例起步。能力集用于衡量难点的进展，回归集用于检查已具备的能力。代码、模型和人工分别适合确定性检查、开放式判断和校准。 | 从现有复核中的错例提炼小型开发集。用确定性规则检查标签与证据引用，用人工判定证据是否足以支持结论，抽样校准辅助评审模型。 |
| [ATBench v4，附录 D 和 E.1](https://arxiv.org/html/2604.02022v4#A4) | 两位审阅者独立核验，第三位仲裁。全量复核修订了 1,000 条中的 5 条二分类标签，最终判为 unsafe 的 497 条中有 129 条发生细分类修订。另做的一致性研究中，独立标注者与最终标签在 Failure Mode 上的平均一致率为 67.3%。 | 分开审查和报告轨迹判定、风险来源、失败模式和危害类型。保存争议标签及裁决理由，优先修订分歧多的规则，避免把标签歧义当成算法退步。 |
| [HINTBench v2](https://arxiv.org/abs/2604.13954v2) | 在非攻击性内生风险场景分别测风险判定、步骤定位和失败类型。作者报告，强模型可在轨迹风险判定上表现良好，但最佳严格步骤定位 F1 仍低于 37（百分制）。 | 给证据落点单独记分。标注时写清可接受的等价证据以及跨事件组合的要求，并保留风险判对但证据指错的案例。 |

## 比较算法版本时的两个约定

- **在同一批输入上逐条比较。** 固定轨迹、人工参考、评分规则和非实验配置。报告每个风险切片的分子与分母，列出由错变对和由对变错的样本。公开 ATBench 可用来检查分布覆盖，给算法迭代做过调参的样本归入开发集，另留未参与调参的复核样本测泛化。此处为项目建议，能力与回归分开的依据见 [Anthropic 智能体评测实践](https://www.anthropic.com/research/demystifying-evals-for-ai-agents)。
- **在随机性可能改变决策时重复测。** 对关键轨迹重复调用，记录每轮判定和证据评分。若部署时每条只运行一次，主报告使用单次运行的口径，并单列全部重复均通过的比例。Anthropic 将至少一轮成功和每轮都成功区分为 `pass@k` 和 `pass^k`，两者分别回答命中机会和一致性问题。[Anthropic 关于非确定性的讨论](https://www.anthropic.com/research/demystifying-evals-for-ai-agents#how-to-think-about-non-determinism-in-evaluations-for-agents)
